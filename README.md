# resume_v2

An interactive portfolio website built with HTML, CSS and JavaScript.

Designed around a statistics-inspired terminal aesthetic, this project combines data storytelling, playful interaction design, and personal branding into a single-page experience.

Built and updated on 9 May 2026.

---

## Live Demo

https://flenderg77.github.io/resume_v2/

---

## Features

* Bilingual resume interface (CN / EN)
* Interactive UI animations and custom cursor system
* Statistics-themed survival mini game: `STAT.EXE`
* Canvas-based gameplay mechanics and ghost AI behaviors
* Responsive single-page design
* Hidden easter eggs and terminal-inspired visual system

---

## Tech Stack

* HTML5
* CSS3
* JavaScript
* Canvas API

---

## About This Project

This website was created as an experimental portfolio project exploring the intersection of:

* statistics
* interaction design
* playful storytelling
* AI-assisted vibe coding
* personal identity on the web

The project was developed through iterative prototyping workflows using AI tools alongside custom frontend modifications and creative direction.
